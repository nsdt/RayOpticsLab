# 論文の実験を再現する手順

[起動方法](../README_JA.md) · [English](REPRODUCING.md)

## 計算する画像を選ぶ

[Ray Optics Lab](https://nsdt.github.io/RayOpticsLab/#paper)を開き、画面上部の **Language / 言語** で日本語を選びます。**「論文の数値実験」** のタブを使用します。ローカルで利用する場合は[起動手順](../README_JA.md#ローカルで使う)を参照してください。この画面の設定と描画結果は、自由描画の設定から独立しています。

収録条件は単色76条件と分散関連4条件の計80条件です。実験の選択は補足資料のFigure S2–S16、S18–S21、S23に対応し、代表的な画像は本文にも掲載されています。参照用の35図には、観察像だけでなく軌道図、差分画像、定量評価のグラフも含まれます。

最初の確認には、均一等方性媒質のパネルを一つ選び、**「掲載画像と同じCPU基準計算」**で計算するとわかりやすくなります。元の解像度と保存済みの実装が使われます。完了後、ファイル・設定の検証が成功したことをステータスで確認します。

## 3種類の計算モード

- **論文の実験条件（GPU優先）**：物理条件、画像サイズ、波長サンプリングを保ちます。計算装置はCPUにも切り替えられます。
- **掲載画像と同じCPU基準計算**：保存済みCPU実装、元の許容誤差、解像度、波長サンプリングをまとめて復元します。保存された基準値との比較にはこのモードを使用します。
- **計算条件を変更して比較**：物理条件は保ったまま、計算装置、画像の一辺（4–1024画素）、波長分割数（8、16、32、64、128、256）を変更できます。

論文の設定をすべて復元するボタンで、条件変更モードから元の実験条件へ戻せます。解像度と波長分割数にも個別の復元ボタンがあります。全設定を復元すると、GPU優先のモードに戻ります。

## 分散例と計算時間

末尾のグループには、均一等方性媒質とreciprocal profileの分散例があります。それぞれに屈折率を波長によらず一定とした条件と、分散を含む条件があります。掲載図では380–780 nmを128分割しています。

試しに像を見る場合は、条件変更モードで小さな画像と8または16波長を選べます。その後、掲載図と同じ条件で確認する際には設定を復元してください。

GPUの初回準備にはシェーダとパイプラインの準備が含まれます。完了後のGPU Workerは再利用できるため、続けて計算すると準備時間が短くなる場合があります。一方、GPUの精度判定を通らない画素はCPUで再計算し、GPUを利用できない環境ではCPUを使います。表示時間にはこれらの処理とデータ転送、波長方向の積算が含まれます。

GPUを選択したというだけでは、全画素がGPUで計算されたことにはなりません。実際に使った装置とCPU補完数を確認してください。GPUの単精度とCPU基準の倍精度は異なる数値実装です。計算記録には、要求した精度設定と実際に適用した設定が残ります。

## 画像と計算記録を保存する

計算が完了したら、次の2つをセットで保存します。

1. PNG画像。
2. その完了画像の計算記録JSON。

計算記録には、画像を生成した条件、ソースのハッシュ、実際の計算装置、精度設定、診断値、画像のハッシュが含まれます。

**「選択中の設定を保存（JSON）」**は別の用途です。計算後にパネルや設定を変更した場合、選択中の設定は表示画像の条件と一致しなくなります。画面にはその旨が表示されますが、完了画像の計算記録は以前の計算条件を保持します。

ファイルの検証エラーが出た場合は、同じ版のファイル一式を使っているか確認して再読み込みします。

`file://` からの直接起動は避け、localhostまたはHTTPSで開きます。

## 参照図と追加解析の再生成

参照図の選択欄では、本文のFigure 1–9と補足資料のFigure S1–S26を表示できます。これは保存された図の表示です。画像計算ボタンで再生成するのは選択した観察像であり、図全体の組版、光線軌道図、定量評価グラフまで一度に生成するわけではありません。

追加解析のダウンロードは `app/paper/analysis-reproduction.zip` です。別のフォルダに展開し、内部のREADMEに従って実行します。これらの解析にはPython、Node.js、および各READMEに記載された数値計算ライブラリが必要です。ブラウザで画像を計算するだけなら不要です。

| アーカイブ内 | 内容 |
| --- | --- |
| `contribution/` | 代表点に接続する光線、誘電体界面の検証、媒質内結合の評価、CPU計算記録 |
| `interfaces/` | 不定計量・変換媒質の界面計算の独立検証、像の変化の分解 |
| `normalization/` | 像の大きさで正規化した代表点の指標 |
| `physical-interpretation/` | heliconicalのπの例、軌道図、reciprocal媒質の直接透過・反射成分 |
| `internal-conversion/` | 媒質内結合の比較と作図用入力 |

アーカイブは過去のスクリプト名と説明を保持しています。図番号の対応は `MANUSCRIPT_MAP.json`、`PHYSICAL_INTERPRETATION_README.md`、各ディレクトリのREADMEを参照してください。現在選択できる80条件は、古いREADME中の条件数ではなく、ブラウザの現行カタログで定義されています。

## 再現性のために保存しているもの

`app/paper/experiments.json` は、現在の既定値との差分ではなく、各画像の完全な設定を持ちます。`app/paper/engine/` は保存済みCPU実装、`app/paper/provenance.json` はエンジン、描画プロトコル、GPUコード、追加解析のハッシュを記録しています。Workerは使用前にこれらを検証します。
