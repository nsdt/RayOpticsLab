Ray Optics Lab

Guide / 利用ガイド

Explore images observed through optical media

Use Custom rendering to change the medium and observation settings. Select Paper experiments to use the saved experimental conditions from the paper. Changing the interface language does not change the settings or the rendered image.

Reproduce an image from the paper

  1. Open Paper experiments, then select the medium and image panel.
  2. Select Paper settings (GPU preferred) to use the paper's physical conditions with GPU calculation where available. Select CPU reference used for the paper to use the preserved CPU implementation and original sampling.
  3. Click Calculate image and wait for the calculation to finish.
  4. Save the image (PNG) and its calculation record (JSON) together. Save selected settings (JSON) is a separate export. If you change the selection after a calculation, the selected settings no longer describe the displayed image.

In the Adjust calculation settings mode, you can choose 4–1024 pixels per side and 8–256 wavelength samples. Restore the original settings before comparing results at the sampling used for the paper figures. The catalog contains 80 experimental conditions and 35 reference figures. Reference figures are saved illustrations. To regenerate ray-trajectory plots and quantitative analyses, use the scripts in the additional-analysis download.

Calculation model

The calculation is based on geometrical optics. Analytical solutions are evaluated where their conditions hold, and numerical integration is used where required. Images are calculated from interface reflection and refraction, the selected polarization approximation, and the weights of the retained ray paths. Changing an approximation can change the physical model.

GPU calculations use single precision. Pixels that fail the accuracy checks are recalculated on the CPU. The preserved CPU reference uses double precision. The calculation record includes source hashes, the numerical precision used and the CPU recalculation count. GPU preparation and CPU recalculation can account for a substantial part of the total time.

光学媒質を通した像を調べる

自由描画では媒質や観察条件を変更できます。保存済みの論文の実験条件を使う場合は論文実験のタブを選びます。表示言語を変えても設定や画像は変わりません。

論文の画像を再現する

  1. 論文実験のタブを開き、媒質と画像のパネルを選びます。
  2. 元の物理条件をGPU優先で計算する場合は「論文の実験条件（GPU優先）」、保存済みCPU実装とサンプリングを再現する場合は「掲載画像と同じCPU基準計算」を選びます。
  3. 画像を計算して完了を待ちます。
  4. PNGとその画像の計算記録JSONをセットで保存します。「選択中の設定」は別の出力です。計算後に選択を変えると、表示画像の条件とは一致しなくなります。

条件変更モードでは一辺4–1024画素、波長分割数8–256を選べます。掲載図と同じサンプリングで比較する前には元の設定を復元してください。80条件と35枚の参照図を収録しています。参照図は保存された図であり、光線軌道図や定量評価の再生成には追加解析のスクリプトを使います。

計算モデル

幾何光学に基づく計算です。適用条件を満たす区間では解析解を評価し、必要な区間には数値計算を使います。界面での反射・屈折、選択した偏光の近似、保持した経路の重みを用いて像を計算します。近似の選択を変えると物理的なモデルも変わる場合があります。

GPUでは単精度を使い、精度判定を通らない画素をCPUで再計算します。保存済みCPU基準は倍精度です。計算済み画像の記録にはソースのハッシュ、実際の精度、CPU補完数が含まれます。GPUの準備やCPU補完に多くの時間がかかる場合もあります。

Spectral calculation / 分散計算

Spectral rendering traces rays at each sampled wavelength and integrates radiance using D65 illumination and the CIE 1931 color-matching functions. The paper figures use 128 samples over 380–780 nm. Fewer samples are useful for exploration, but convergence should be checked before quantitative comparisons.

分散計算では波長ごとに光線を追跡し、D65照明とCIE 1931等色関数を用いて輝度を積算します。掲載図は380–780 nmを128分割しています。少ない分割数は探索に便利ですが、定量比較の前には収束を確認してください。

Additional analysis / 追加解析

Download analysis scripts and records / 解析スクリプトと記録をダウンロード

Extract the archive and follow the included README files. The additional analyses require Python or Node.js and the listed libraries. Browser image calculations do not require these dependencies. Historical figure numbers and names are preserved in the archive.

展開後にアーカイブ内のREADMEを参照してください。追加解析にはPythonやNode.jsの依存ライブラリが必要ですが、ブラウザでの画像計算には不要です。アーカイブ中の過去の図番号や名称は保持されています。
