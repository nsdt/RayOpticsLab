Ray Optics Lab

Guide / 利用ガイド

Images through optical media

Use Custom rendering to change material and observation settings. Use Manuscript experiments for the retained paper conditions. The language selector changes the interface without changing the scene or image.

Reproduce a paper image

  1. Open Manuscript experiments, then select the medium and image panel.
  2. Choose Manuscript experiment — GPU preferred for the original physical scene with GPU preference, or Archived CPU reference for the retained CPU implementation and sampling.
  3. Calculate the image and wait for completion.
  4. Save the PNG and its completed calculation record together. Selected settings are a separate export and may differ from the displayed image after a selection change.

Adjust calculation settings permits 4–1024 pixels per side and 8–256 wavelength samples. Restore the manuscript settings before comparing at the original sampling. The catalog contains 80 image conditions and 35 reference figures. Reference figures are saved illustrations; trajectory and quantitative plots use the additional-analysis scripts.

Calculation model

The application uses geometrical optics. Analytical trajectories are evaluated where their conditions hold, with numerical propagation where required. Interface reflection and refraction, the selected polarization approximation and retained path weights determine the image. Changing an approximation can change the physical model.

WebGPU uses float32 arithmetic. Pixels that fail precision guards are retraced on CPU. The archived CPU reference uses float64. Source hashes, effective precision and fallback counts are included in the completed record. GPU preparation and CPU fallback may dominate elapsed time.

光学媒質を通した像を調べる

自由描画では媒質や観察条件を変更できます。論文の保存された条件を使う場合は論文実験のタブを選びます。表示言語を変えても設定や画像は変わりません。

論文の画像を再現する

  1. 論文実験のタブを開き、媒質と画像のパネルを選びます。
  2. 元の物理条件をGPU優先で計算する場合は「論文の実験条件（GPU優先）」、保存済みCPU実装とサンプリングを再現する場合は「掲載画像と同じCPU基準計算」を選びます。
  3. 画像を計算して完了を待ちます。
  4. PNGとその完了画像の計算記録JSONをセットで保存します。「選択中の設定」は別の出力です。計算後に選択を変えると、表示画像の条件とは一致しなくなります。

条件変更モードでは一辺4–1024画素、波長分割数8–256を選べます。掲載図と同じサンプリングで比較する前には元の設定を復元してください。80条件と35枚の参照図を収録しています。参照図は保存された図であり、光線軌道図や定量評価の再生成には追加解析のスクリプトを使います。

計算モデル

幾何光学に基づく計算です。適用条件を満たす区間では解析解を評価し、必要な区間には数値計算を使います。界面での反射・屈折、選択した偏光の近似、保持した経路の重みを用いて像を計算します。近似の選択を変えると物理的なモデルも変わる場合があります。

GPUでは単精度を使い、精度判定を通らない画素をCPUで再計算します。保存済みCPU基準は倍精度です。完了画像の記録にはソースのハッシュ、実際の精度、CPU補完数が含まれます。GPUの準備やCPU補完に多くの時間がかかる場合もあります。

Spectral calculation / 分散計算

Spectral rendering traces wavelength samples and integrates radiance with D65 illumination and the CIE 1931 observer. The manuscript uses 128 samples over 380–780 nm. A smaller sample count is useful for exploration, but convergence should be checked before quantitative comparison.

分散計算では波長ごとに光線を追跡し、D65照明とCIE 1931等色関数を用いて輝度を積算します。掲載図は380–780 nmを128分割しています。少ない分割数は探索に便利ですが、定量比較の前には収束を確認してください。

Download analysis scripts and records / 解析スクリプトと記録をダウンロード

Extract the archive and follow its READMEs. Python/Node.js dependencies are needed for these additional analyses, not for browser rendering. Historical labels in the archive are retained.

展開後にアーカイブ内のREADMEを参照してください。追加解析にはPythonやNode.jsの依存ライブラリが必要ですが、ブラウザでの画像計算には不要です。アーカイブ中の過去の図番号や名称は保持されています。
