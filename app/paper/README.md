# Manuscript reproduction runtime

This directory is self-contained at runtime. It includes:

- `experiments.json`: 80 complete image configurations (76 monochromatic, 4 spectral).
- `engine/`: the preserved CPU implementation used by the image protocol.
- `selection.js`, `protocol.js`, `worker.js`: selection validation, rendering and verified loading.
- `provenance.json`: source, configuration, GPU and analysis-archive hashes.
- `figures/`: 35 reference illustrations (article 1–9 and Supplement S1–S26).
- `analysis-reproduction.zip`: retained additional numerical and plotting analyses.

The catalog protocol is `manuscript-20261116-coupling`; the archived image protocol
is `manuscript-20260928`. GPU and archived CPU are separate arithmetic paths.
The worker verifies the source files before calculation. Do not edit the historical
engine merely to share code with the live app.

Select an experiment, choose the manuscript/GPU, archived CPU or adjusted mode,
calculate, then save the PNG together with its completed calculation record.
Selected settings and completed-image records are separate exports.

The reference selector displays saved figures. The image calculation regenerates
a camera image; additional trajectory and quantitative plots are generated by the
scripts in the analysis archive. Historical labels inside that archive are retained.

In the source repository, detailed instructions are in `docs/REPRODUCING.md` and
`docs/REPRODUCING_JA.md`. The browser application itself does not require those docs
or any of the original development workspace paths.
